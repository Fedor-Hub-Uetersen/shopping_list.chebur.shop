# shopping_list.chebur.shop
# 🛒 Умный список покупок (Smart Shopping List)

Удобный, легкий и современный веб-инструмент для управления покупками с поддержкой мультиязычности, расчётом бюджета, темной темой и возможностью печати. Работает прямо в браузере и сохраняет все данные локально.

## ✨ Возможности

* **Мультиязычность:** Поддержка русского, украинского и немецкого языков (`RU`, `UA`, `DE`).
* **Темная и светлая тема:** Переключение в один клик с сохранением выбора.
* **Управление бюджетом:** Автоматический подсчёт общей суммы некупленных товаров.
* **Категории:** Стандартные разделы («Продукты», «Дом», «Здоровье», «Разное») с возможностью добавления и удаления собственных категорий.
* **Экспорт и копирование:** Удобное модальное окно для копирования списка в буфер обмена для отправки в мессенджеры.
* **Печать:** Адаптированная версия для печати перед походом в магазин.
* **Автосохранение:** Все изменения мгновенно сохраняются в памяти браузера (`localStorage`).

## 🚀 Как запустить

1. Скачайте или скопируйте файл `index.html`.
2. Дважды кликните по нему, чтобы открыть в любом современном браузере.
3. Готово! Никаких серверов и установок не требуется.
